# Design System

## Direction

The supplied homepage image is the visual source of truth: an immersive Malaysian rainforest, warm sunlight, deep green surfaces, restrained gold accents, translucent navigation and editorial typography. The same language is applied to all eleven pages.

## Color palette

| Name | Hex | Use |
| --- | --- | --- |
| Canopy | `#062C22` | Primary dark green |
| Rainforest | `#0A4635` | Cards and secondary surfaces |
| Moss | `#6F8B55` | Supporting natural accent |
| Sunlit Gold | `#D6A84B` | Buttons and active states |
| Warm Sand | `#E8D3A1` | Display headings and premium accents |
| Ivory | `#F8F4EA` | High-contrast text |

## Typography

- **Cormorant Garamond** — display headings, section titles and brand wordmark. It gives the pages the elegant conservation-editorial feeling shown in the selected homepage.
- **Manrope** — navigation, body copy, labels, buttons and data. It stays clean and readable on mobile and in dense visitor-information layouts.

Both fonts are packaged locally through Fontsource, so they do not rely on Google Fonts at runtime.

## Core components

- Glass navigation and dropdowns
- Gold primary button and transparent secondary button
- Editorial section headings with eyebrow labels
- Dark bordered information cards
- Full-screen image viewer
- Responsive data table
- Fixed quick actions for tickets and map
- Shared footer and contact treatment
